# Как открыть и проверить материалы

На GitHub по клику на `.html` виден **код**, а не презентация.  
Чтобы увидеть буклет, слайды и маркетплейс — откройте файлы **в браузере** (Chrome, Safari, Edge, Firefox).

---

## Шаг 1. Получить доступ к репозиторию

1. Примите приглашение в репозиторий (письмо от GitHub или [страница приглашений](https://github.com/pereskokovalexey833-hub/campus-360-materials/invitations)).
2. Откройте репозиторий:  
   https://github.com/pereskokovalexey833-hub/campus-360-materials

---

## Шаг 2. Скачать файлы на компьютер

### Способ A — ZIP (проще всего)

1. На странице репозитория нажмите зелёную кнопку **Code**.
2. Выберите **Download ZIP**.
3. Распакуйте архив в любую папку (например, «Загрузки»).

### Способ B — через Git

```bash
git clone https://github.com/pereskokovalexey833-hub/campus-360-materials.git
cd campus-360-materials
```

---

## Шаг 3. Открыть оглавление в браузере

1. Зайдите в папку с файлами.
2. Дважды кликните по файлу **`index.html`**.
3. Откроется оглавление со ссылками на все материалы.

Либо из терминала (macOS):

```bash
open index.html
```

На Windows:

```bash
start index.html
```

---

## Шаг 4. Что открывать и как тестировать

| Файл | Что проверить |
|---|---|
| `index.html` | Оглавление, все ссылки открываются |
| `campus-360-booklet.html` | Листается **вниз**. Скрины не обрезаны, есть обложка и разделы |
| `campus-360-modules-prices.html` | Слайды: **← →** или пробел. Тарифы 6–40 тыс ₽ |
| `neurotests-marketplace.html` | Карточки тестов, фильтры, **корзина**, батареи, форма заявки |
| `neurotests-presentation.html` | Слайды ← →. Есть блок про батареи и каталог тестов |

### Навигация

- **Презентации** (модули/цены, NeuroTests): клавиши `←` `→`, `PageUp` / `PageDown`, пробел.
- **Буклет**: обычный скролл колесом / трекпадом вниз.
- **Маркетплейс**: клики мышкой (фильтры, «В корзину», корзина).

---

## Частые ошибки

| Проблема | Решение |
|---|---|
| На GitHub виден только код | Скачайте ZIP / clone и откройте файл двойным кликом |
| Файл открылся в Cursor / VS Code | ПКМ по файлу → «Open With» → Chrome / Safari |
| Сломались картинки в буклете | Открывайте HTML из папки репозитория целиком (не вытаскивайте один файл без `assets/`) |
| Не открывается репозиторий | Примите приглашение collaborator |

## Состав материалов

1. **Буклет Campus 360** — продукт и функционал со скриншотами.

4. **Презентация NeuroTests** — все тесты + отдельный блок батарей.
